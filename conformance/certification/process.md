# Certification Program

## Process

1. Self-assess against compliance profile (C0–C6)
2. Run CTS-1.0 suite
3. Submit evidence per [../evidence-requirements/evidence-schema.md](../evidence-requirements/evidence-schema.md)
4. Independent reviewer validates resolution-map coverage
5. Badge issued with provenance entry
