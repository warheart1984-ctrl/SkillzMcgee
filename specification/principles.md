# Constitutional Principles

**Authority:** CRK-1 Specification v1.0  
**Status:** Normative

## Purpose

CRK-1 is a **constitutional runtime**: a governed substrate where every action is consequence-bound, evidence-producing, interpretation-exposed, governance-validated, provenance-anchored, semantically replayable, and drift-monitored.

CRK-1 is not a framework, library, or agent. It is the law that runtimes obey.

## Core Guarantees

| Guarantee | Meaning |
|-----------|---------|
| **Continuity** | No insulation from consequences |
| **Interpretability** | All behavior explainable through V1 vocabulary |
| **Traceability** | Every action linked to evidence and governance |
| **Reproducibility** | All outputs reconstructible from inputs |
| **Provenance** | All changes historically anchored |
| **Founder independence** | No tribal knowledge required |

## Architectural Gravity (AGS-1.0)

Constitutional center of mass:

- Invariant Engine (IE-CORE)
- Governance Kernel (GOV-KERN-1)
- Traceability Ledger (TL-1)
- Receipts Schema (REC-1.0)

Gravitational forces:

- **F1 — Invariant Pull:** New concepts map to existing invariants or declare a proposal.
- **F2 — Scope Compression:** Subsystems exceeding domain are compressed back.
- **F3 — Interpretability Field:** Claims must use Version-1.0 vocabulary.
- **F4 — Reproducibility Gravity:** Non-reproducible components are massless.

Conceptual gravity: `G = I × T × R` (invariant alignment × traceability × reproducibility).

## Version 1.0 Boundaries

Version 1.0 **includes** CRK-1, COM-1.0, four contracts, K0–K12, TL-1, REC-1.0, URIT-MAP, AGS, STAB-1.0, V1-CONV-CHK.

Version 1.0 **excludes** autonomous invariant mutation, new constitutional objects, new governance layers, semantic self-modification, and non-reproducible subsystems.
