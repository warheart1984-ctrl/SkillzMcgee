# NEGOTIANTS: A Modal Roleplaying Game

**Engine:** Negotiant Core (⟴) v1.0.0  
**Chapter 1 — Draft**

## 1.1 What Is a Negotiant?

A Negotiant is a being who perceives the world not as fixed, but as a field of tensions in constant negotiation.

Every action, conflict, spell, and transformation is a shift in the five tensions:

- Becoming
- Resistance
- Memory
- Horizon
- Equilibrium

The Core (⟴) governs how these tensions evolve. Players do not "roll to hit." They roll to negotiate.

## 1.2 The Core Loop

Every action in the RPG is a rotation of the Core:

1. Identify tensions
2. Roll to negotiate
3. Apply mode shift
4. Resolve backlash
5. Update the world

This is the same loop used by the interpreter, the governance kernel, the cosmology, and the scripture. The RPG is the playable face of the Core.

## 1.3 Character Sheet = Tension Profile

A character is defined by five tensions (1–10). These are not stats. They are modal tendencies.

## 1.4 Actions = Negotiations

- **Becoming** → creation, assertion, initiative
- **Resistance** → defense, refusal, defiance
- **Memory** → recall, lineage, echoes
- **Horizon** → possibility, foresight, risk
- **Equilibrium** → balance, nullification, harmony

The GM interprets outcomes using the RPG face (`src/faces/rpg/view.js`).

## 1.5 Backlash

When tensions diverge too far, backlash occurs: paradox, instability, fractures, unintended consequences. Backlash is the RPG's drama engine.

## 1.6 Worlds as Tension Fields

Worlds are tension distributions. The cosmology face provides the world's tier. The RPG face provides the world's behavior.
