## Dimensions

### Layer

| Value | Description |
|-------|-------------|
| Protocol | Wire-level or semantic interchange rules |
| Runtime | Execution environment with governed behavior |
| Governance | Decision-making, stewardship, amendment processes |
| Standard | Normative specification others implement against |
| Institution | Durable body that maintains continuity across generations |

### Temporal Horizon

| Value | Description |
|-------|-------------|
| 5â€“20 years | Generational tooling or platform |
| 20â€“100 years | Infrastructure-class substrate |
| Multi-generational | Constitutional or protocol-level permanence |

### Scope

| Value | Description |
|-------|-------------|
| Local | Single org or domain |
| National | Jurisdiction or industry vertical |
| Global | Cross-border adoption |
| Planetary | Universal substrate (e.g., internet protocols) |

### Coupling

| Value | Description |
|-------|-------------|
| Tightly coupled | Runtime + standard inseparable (e.g., constitutional OS) |
| Loosely coupled | Policy or governance separate from implementation |

### Adoptability

| Value | Description |
|-------|-------------|
| Open standard | Anyone may implement; conformance is measurable |
| Proprietary | Controlled by single vendor |
| Stewarded commons | Open with formal governance body |
