# Continuity OS v1.0 — Evidence, Not Assertions

Continuity OS v1.0 is the first constitutional runtime designed to make its guarantees **inspectable**, **reproducible**, and **independently verifiable**.

Most systems ask you to trust their architecture.  
**Continuity OS asks you to query it.**

---

## A constitutional architecture

Continuity OS defines:

- a constitutional model,
- transformation specifications,
- normative requirements,
- governance rules.

These documents live in `/specification/` and describe what the system is **designed** to guarantee.

## A conformance ecosystem

The runtime produces:

- transformation records,
- evidence,
- receipts,
- provenance.

These artifacts show what the system **actually** does.

## An observability layer

Continuity OS v1.0 includes:

| Instrument | Role |
|------------|------|
| Proof graph | Traceability index |
| CSR-1.0 | Claim maturity registry |
| COR-1.0 | Constitutional observability report |
| DRA-1.0 | Dependency-risk analyzer |
| Counterfactual engine | What-if analysis |
| Query API | `crk query` |

These tools make the system **self-auditing**. They are derived — regenerated from canonical state, never hand-edited.

## A governance layer

Stewards evaluate measured state (COR, CSR, DRA, CAV) against [RCD-1.0](../../conformance/certification/RCD-1.0.md) and record decisions in the **Governance Ledger** — canonical, append-only, separate from measurement.

## Evidence over assertions

Every claim in the repository is:

| Status | Meaning |
|--------|---------|
| **Normative** | Required by the spec |
| **Implemented** | Demonstrated by a runtime |
| **Verified** | Validated by the conformance ecosystem |
| **Reproduced** | Independently confirmed |
| **Research** | Explicitly outside v1.0 guarantees |

There is no undocumented middle ground.

## Founder-independence

Version 1.0 is designed so that an external team can:

- reconstruct the architecture from `/specification/`,
- verify every claim via COR/CSR,
- reproduce results via R1-0,
- understand why every artifact exists —

**without relying on founder knowledge.**

See the [External Auditor Handbook](../../conformance/certification/external-auditor-handbook-v1.0.md).

## Query it yourself

```bash
npm run spec:rebuild
node tools/crk.mjs rcd evaluate
node tools/crk.mjs orc evaluate
node tools/crk.mjs dra top-blockers
node tools/crk.mjs gls list
```

And every measurement is open.
