## 1. Purpose

This quickstart teaches operators how to interact with constitutional state using Investigation Mode and the Version 1.0 runtime.

---

## 2. Operator Responsibilities

Operators must:

- inspect constitutional state
- validate lineage
- review evidence
- detect drift
- confirm reproducibility
- escalate governance issues

Operators do **not** modify the Constitution.

**Governance charter:** [../../spec/governance-charter-1.0.md](../../spec/governance-charter-1.0.md)

---

## 3. Core Tools

### 3.1 Readiness Summary

Shows CAR, CAV, COR, PGI, DRA, and governance status.

### 3.2 Lineage Explorer

Visualizes proof graph, dependencies, and traceability.

**See:** [../../conformance/proof-graph/README.md](../../conformance/proof-graph/README.md)

### 3.3 Drift Map

Shows drift envelopes and deviations.

**See:** [../../conformance/observability/DRA-1.0/spec.md](../../conformance/observability/DRA-1.0/spec.md)

### 3.4 Counterfactuals

Simulates changes to requirements, evidence, or decisions.

### 3.5 Artifact Dumps

Displays raw constitutional artifacts.

**See:** [../../spec/CAR-1.0-Registry.md](../../spec/CAR-1.0-Registry.md)

---

## 4. Operator Workflow

1. Load constitutional state
2. Check readiness
3. Inspect lineage
4. Review evidence
5. Analyze drift
6. Validate reproducibility
7. Document findings
8. Escalate governance decisions

---

## 5. Anti-Patterns

Operators must **not**:

- bypass governance
- rely on intuition
- accept untraceable outputs
- modify canonical artifacts
- introduce hidden state

---

## 6. Completion

You are ready to operate when you can:

- navigate Investigation Mode
- validate constitutional state
- interpret drift
- trace lineage
- confirm reproducibility
