## Getting Help

### Questions and Discussions

For questions about:
- SkillzMcGee architecture
- Continuity OS operations
- Reality stack implementation
- Substration engine usage
- CRK-1 principles

Please open a [GitHub Discussion](https://github.com/your-org/skillzmcgee/discussions) with the appropriate category.

### Bug Reports

If you encounter a bug, please:
1. Check existing [GitHub Issues](https://github.com/your-org/skillzmcgee/issues)
2. If not already reported, open a new issue using the bug report template
3. Include environment details, reproduction steps, and expected behavior

### Feature Requests

We welcome feature requests! Please:
1. Check existing [GitHub Issues](https://github.com/your-org/skillzmcgee/issues)
2. Open a new issue using the feature request template
3. Describe the problem, proposed solution, and alternatives considered

## Governance Support

For questions about governance and continuity:
- Review the governance principles documentation
- Check the continuity ledger documentation
- Open a discussion with the "governance" label

## Security Issues

**Do NOT** report security vulnerabilities via public issues.

Please report security vulnerabilities to: security@example.com

See [SECURITY.md](SECURITY.md) for more details.

## Community

Join our community to connect with other users and contributors:
- GitHub Discussions
- GitHub Issues
- Pull Requests

## Response Time

We aim to respond to:
- Security vulnerabilities: Within 24 hours
- Bug reports: Within 3-5 business days
- Feature requests: Within 1 week
- General questions: As time permits
