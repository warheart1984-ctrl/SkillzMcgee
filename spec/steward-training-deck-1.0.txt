SECTION 1 — WHAT IS A STEWARD?
-----------------------------------------------------------
A steward is a constitutional guardian.
Stewards protect:
  • the baseline
  • the invariants
  • the semantic grammar
  • the reproducibility guarantees
  • the identity of the platform

Stewards do NOT:
  • maintain code
  • manage product features
  • optimize performance
  • own operational tooling

Stewards govern the Constitution, not the implementation.


SECTION 2 — THE CONSTITUTIONAL BASELINE
-----------------------------------------------------------
The baseline consists of:
  • CAR-1.0
  • Authority → Specification → Implementation → Execution
  • One-artifact-per-stage invariant
  • Proof graph model
  • Evidence + provenance model
  • Validation → Measurement → Analysis → Governance
  • Reproducibility requirement

This baseline is frozen.

Reference: spec/constitutional-baseline-1.0.md


SECTION 3 — THE STEWARD'S MISSION
-----------------------------------------------------------
1. Preserve constitutional semantics.
2. Prevent drift.
3. Maintain compatibility.
4. Ensure all changes are evidence-backed.
5. Maintain founder-independence.
6. Uphold transparency.


SECTION 4 — HOW TO REVIEW A CHANGE
-----------------------------------------------------------
Ask:
  • Does it alter the baseline?
  • Does it change semantics?
  • Does it break reproducibility?
  • Does it violate invariants?
  • Does it change artifact categories?
  • Does it alter the constitutional loop?
  • Does it modify proof graph semantics?

If yes → Constitutional Amendment (2.0)
If no → Minor or Patch

Reference: spec/amendment-procedure-1.0.md · spec/constitutional-evolution-guidelines.md


SECTION 5 — VERSIONING DISCIPLINE
-----------------------------------------------------------
Patch (1.0.x)
  • Clarifications
  • Non-semantic corrections

Minor (1.x)
  • New capabilities
  • Optional extensions
  • No baseline changes

Major (2.0)
  • Constitutional amendments
  • Baseline changes
  • Semantic changes


SECTION 6 — THE STEWARD MINDSET
-----------------------------------------------------------
Stewards must:
  • Think in invariants
  • Reason in semantics
  • Govern with evidence
  • Avoid founder bias
  • Maintain neutrality
  • Protect identity

Stewards are custodians of continuity.


SECTION 7 — COMPLETION
-----------------------------------------------------------
A steward is trained when they can:
  • Identify constitutional vs operational changes
  • Evaluate compatibility
  • Apply the amendment procedure
  • Maintain semantic stability
  • Govern evolution responsibly
