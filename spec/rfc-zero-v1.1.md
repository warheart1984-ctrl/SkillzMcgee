### 1. Purpose

### 2. Constraints

Version 1.1 **must**:

- preserve the constitutional baseline
- preserve CAR-1.0
- preserve invariants
- preserve proof graph semantics
- preserve reproducibility

Version 1.1 **may**:

- extend capability
- improve tooling
- enhance operator experience
- expand modeling suite
- add optional conformance profiles
