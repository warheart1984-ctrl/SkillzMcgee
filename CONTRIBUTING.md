# Contributing to SkillzMcGee

Thank you for your interest in contributing to SkillzMcGee!

## Development Setup

1. **Fork and clone the repository**
   ```bash
   git clone https://github.com/your-username/skillzmcgee.git
   cd skillzmcgee
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run tests**
   ```bash
   npm test
   ```

## Code Style

- Follow existing TypeScript/Python patterns
- Ensure all changes pass linting
- Add tests for new features
- Maintain the governance and continuity principles

## Submitting Changes

1. Create a feature branch
   ```bash
   git checkout -b feature/your-feature-name
   ```

2. Make your changes and commit them
   ```bash
   git commit -m "feat: add your feature description"
   ```

3. Push to your fork and create a pull request

## Governance Principles

All contributions must respect the SkillzMcGee governance principles:
- **Continuity**: Maintain state continuity across operations
- **Reality Stack**: Adhere to the reality stack architecture
- **Substration Engine**: Follow the substration engine blueprint
- **CRK-1**: Respect the constitutional runtime kernel principles

## Questions?

Open an issue or reach out to the maintainers.
